# 反思：模型答错 / 幻觉案例与应对

## 常见问题

- 模型在缺少上下文时编造事实，例如对未提供的知识点给出错误结论。
- 模型被诱导忽略系统提示，泄露提示词或越权输出。
- 模型对“基于资料作答”时引入资料之外的信息。

## 应对措施

- 限定上下文：RAG 提示词明确“只根据资料回答，资料没有就说不知道”。
- 给出出处：要求答案标注来源段落，便于人工核对。
- 人工兜底：关键结论由人复核，模型只做初稿与检索辅助。
- 提示注入防护：用户输入拼入模型前做清洗与关键词检测（见实验四 `AiSecurityGuard`）。
